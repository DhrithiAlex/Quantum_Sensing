# Fisher Information Limits for Phase Estimation
### From continuous-variable homodyne detection (thesis) to discrete-variable Ramsey/GHZ interferometry (this project)

Author: Dhrithi Maria
Companion project to: *Balanced Homodyne Detection without Coherent State Local Oscillator* (M.Sc. Thesis, Universität Paderborn, 2026)

---

## 1. Why this project exists

The thesis develops a calibration-based framework for extracting the **precision** with which a quadrature (and hence a phase) can be estimated from a continuous-variable homodyne measurement, without assuming an idealised local oscillator. What the thesis does not do — and what this project adds — is make that precision limit explicit in the language of **quantum estimation theory**: the Quantum Fisher Information (QFI) and the Quantum Cramér–Rao Bound (QCRB).

This project translates the same underlying question — *how precisely can a phase be extracted from a given measurement strategy, and what is the best any measurement could do?* — into the discrete-variable, gate-model setting, implemented and verified in Qiskit. It is the natural theoretical extension the thesis identifies but does not pursue (see thesis §7.1.1, *Implications and future extensions*), and it directly reuses the thesis's own notation and conventions wherever the two formalisms coincide.

## 2. Recap: where phase and precision enter the thesis

From the thesis (Ch. 1–2), a phase shift φ is applied to the LO before the beam splitter,

  b̂ → e^{iφ} b̂,        (thesis Eq. 1.3)

and the measured difference photocurrent in the strong-LO (textbook) limit is

  δ̂(φ) ≈ √(2|α|) ( x̂ cos φ + p̂ sin φ ).     (thesis Eq. 1.6)

The mean and variance of this single observable carry all the information about the signal's quadratures at that phase setting:

  ⟨δ̂(φ)⟩ ∝ mean quadrature,   Var(δ̂(φ)) ∝ quadrature variance.   (thesis Eq. 1.7)

This is already, implicitly, a parameter-estimation statement: φ (or more precisely, a signal phase encoded in x̂, p̂) is inferred from the statistics of a single scalar observable, and the *precision* of that inference is set by how sharply Var(δ̂(φ)) is peaked as φ is scanned — exactly the quantity Fisher information formalizes.

Two features of the thesis carry over directly:

1. **The measurement precision depends on the state, not just the measurement setup.** The thesis shows this via squeezing (Ch. 5): a squeezed-vacuum signal reduces Var(δ̂(φ)) below the vacuum/shot-noise level along one quadrature. The same logic reappears here as **entanglement reducing the achievable phase variance below the shot-noise/standard quantum limit (SQL)**.
2. **The "textbook" high-|α| limit sets a reference precision (shot-noise-limited estimation), and departures from that reference (squeezing, LO imperfection) shift the achievable precision away from it.** In the DV setting, the reference precision is the SQL set by N independent (unentangled) qubits/photons, and entangled probe states (GHZ states) shift precision toward the **Heisenberg limit**.

## 3. The estimation-theory formalism (new to this project)

### 3.1 Classical Fisher Information (CFI)

For a measurement with outcome probabilities P(k | θ) depending on a parameter θ,

  F_C(θ) = Σ_k [1 / P(k|θ)] · (∂P(k|θ)/∂θ)²

The **Classical Cramér–Rao Bound** for an unbiased estimator over M independent repetitions:

  Var(θ̂) ≥ 1 / (M · F_C(θ))

### 3.2 Quantum Fisher Information (QFI)

Maximising F_C over *every possible measurement* on the probe state ρ(θ) gives the QFI, F_Q(θ) ≥ F_C(θ) for any measurement, with equality for the optimal one. For a pure state |ψ(θ)⟩ = e^{-iθ Ĝ} |ψ(0)⟩ generated by a Hermitian generator Ĝ,

  F_Q(θ) = 4 Var(Ĝ) = 4 ( ⟨ψ|Ĝ²|ψ⟩ − ⟨ψ|Ĝ|ψ⟩² )

giving the **Quantum Cramér–Rao Bound (QCRB)**:

  Var(θ̂) ≥ 1 / (M · F_Q(θ))

### 3.3 The direct analogy to the thesis

| Thesis (CV, homodyne)                                   | This project (DV, gate-model)                         |
|-----------------------------------------------------------|---------------------------------------------------------|
| Phase shift φ applied to LO mode b̂                        | Phase θ encoded via a Z-rotation on a qubit register     |
| Difference photocurrent δ̂(φ), Eq. 1.5                     | Parity / computational-basis measurement outcome          |
| Var(δ̂(φ)) sets estimation precision, Eq. 1.7               | Var(θ̂) bounded by 1/F_C, 1/F_Q                          |
| Strong coherent LO, \|α\|≫1 (textbook limit), shot noise ∝ \|α\|² | N unentangled qubits/photons: SQL, F_Q = N               |
| Squeezed-vacuum signal reduces Var(δ̂) below shot noise (Ch. 5) | N-qubit GHZ state: F_Q = N², Heisenberg limit           |
| D-criterion certifies non-classicality independent of LO state (Ch. 5) | QFI certifies metrological usefulness independent of the specific measurement chosen |

The standard optical result behind the thesis's textbook limit is F_Q = 4|α|² for a coherent-state phase probe — i.e. N = |α|² photons gives shot-noise scaling F_Q ∝ N. This project's single-qubit Ramsey case (F_Q = 1 per qubit, N qubits used independently → F_Q = N) is the exact discrete-variable restatement of that same shot-noise scaling law. The GHZ case (F_Q = N²) is the qubit-register analog of what squeezing achieves on the continuous-variable side: both beat the shot-noise/SQL scaling by exploiting non-classical correlations (squeezing correlates quadrature fluctuations; GHZ entanglement correlates qubit measurement outcomes), at the cost of higher noise sensitivity — which is exactly the trade-off the thesis's robustness/stress-test chapter (Ch. 5) explores for squeezing, and which the companion noise/calibration project (next in this series) will explore for GHZ dephasing.

## 4. What `phase_estimation.py` implements

1. **Single-qubit Ramsey interferometry**: H → RZ(θ) → H → measure. Encodes θ via phase-kickback, the DV analog of the LO phase shifter (thesis Eq. 1.3).
2. **N-qubit GHZ interferometry**: (H, CNOT chain) → collective RZ(θ) on all N qubits → disentangling circuit → parity measurement. This is the entangled probe state achieving Heisenberg scaling.
3. **CFI estimated numerically** from measured outcome probabilities via a central finite-difference on P(k|θ), matching how the thesis's Ch. 4 calibration procedure extracts variance from measured statistics rather than assuming it analytically.
4. **QFI computed analytically** (F_Q = N for independent qubits, F_Q = N² for GHZ) and plotted alongside the CFI estimates and both bounds (SQL ∝ 1/N, Heisenberg ∝ 1/N²) as N is scanned.
5. **A depolarizing/dephasing noise model** (Qiskit Aer) is applied to both circuit families to show how noise degrades the GHZ state's Heisenberg advantage — the entry point for the next project in this series (LO-agnostic-style calibration and error mitigation for entangled sensing probes).
